# Security Policy

This repository is currently a starter and does not yet contain application
code. Security reports are still welcome, especially for exposed credentials,
unsafe starter defaults, or vulnerabilities in included project files.

## Reporting a vulnerability

Please do not report security issues in public issues or pull requests. Use
GitHub's **Report a vulnerability** option in the repository's Security tab
when private vulnerability reporting is enabled. If that option is unavailable,
use a private contact method listed on the maintainer's
[@franchodl GitHub profile](https://github.com/franchodl).

Include the affected file or component, the impact, and steps to reproduce
where safe. Please avoid sharing real secrets or personal data in a report.

There is no formal response-time guarantee yet. The maintainer will review
reports and coordinate any fix and disclosure with the reporter.
