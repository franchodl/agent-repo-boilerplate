# Contributing

Thanks for helping improve this starter. Contributions should make it easier
for others to start and maintain a React + Django application. Please follow
the repository's [Code of Conduct](./CODE_OF_CONDUCT.md).

## Before opening a pull request

- For large changes, open an issue first to agree on the problem and scope.
- Keep each change focused and follow the existing repository conventions.
- Update relevant documentation, including setup instructions when adding
  tooling or application scaffolding.
- Add focused tests for behavior changes and run the relevant checks. The
  current repository does not yet include application code or test commands;
  document any checks you add.
- Do not include credentials, local configuration, generated output, or
  unlicensed third-party material. Clearly attribute and preserve notices for
  third-party work where required.

## Pull requests

Describe the problem, the change, and how you verified it. For UI work, include
screenshots when useful and note accessibility or responsive behavior checked.
Keep unrelated cleanup in a separate pull request.
